사주명리학 용어 데이터베이스 + 오프라인 웹 트리뷰

용어: 245개 / 관계: 150개 / 계산 규칙: 8개

사용법
1. index.html을 Chrome 또는 Edge로 열면 인터넷 없이 작동합니다.
2. 왼쪽 카테고리를 펼치거나 검색창에 한글/한자를 입력합니다.
3. 용어를 누르면 정의, 분류, 관련 용어, 출처 구분이 표시됩니다.
4. saju_terms.sqlite는 SQLite 데이터베이스입니다.
5. saju_terms.csv는 엑셀에서 열 수 있고 saju_terms.json은 개발용 데이터입니다.

주의: 용어 백과 초판입니다. 일부 신살과 격국은 학파마다 정의가 다릅니다.
고전 문헌은 참고 문헌으로만 표기하며 개별 항목에 대해 원전 쪽수 검증을 마치지 않았습니다.
실제 생년월일시 입력 사주 계산기는 포함되지 않습니다.
