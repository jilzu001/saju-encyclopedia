# 사주명리학 용어 백과

공개 사이트: https://jilzu001.github.io/saju-encyclopedia/

저장소: https://github.com/jilzu001/saju-encyclopedia

`DEVELOPMENT_SPEC.md`를 최상위 명세로 적용했습니다. 사용자의 후속 요청에 따라 사주 계산과 짧은 8장 읽기를 추가했습니다. 원본 명세는 그대로 보존하며 변경 범위는 `SCOPE_UPDATES.md`에 기록합니다.

## 이용 방법

- 백과 홈에서 9개 대분류를 선택하고 중분류를 펼쳐 용어를 읽습니다. PC에서는 왼쪽 트리도 쓸 수 있습니다.
- 검색창에 한글·한자·정의·분류를 입력합니다. 관련 용어와 목록으로 버튼으로 이어서 탐색합니다.
- `가− / 가+`로 18~26px를 선택합니다. 기본값은 20px이며 이 설정만 브라우저에 저장합니다.
- 사주보기에서 양력/한국 음력을 고르고 연도·월·일·시·분을 눌러 선택합니다. 타이핑 없이 사용할 수 있습니다. 일 목록은 윤년과 한국 음력/윤달에 맞게 갱신됩니다. 대운은 시간과 전통 계산에 사용할 성별을 선택해야 합니다.
- 날짜 변경의 기본값은 자시 시작인 밤 11시입니다. 자정 기준은 ‘계산 기준 변경’을 펼쳐 선택할 수 있습니다. 국내 만세력 전체가 같은 기준을 쓰는 것은 아니므로 ‘한국의 단일 표준/다수 사용이 통계로 확인됨’으로 표시하지 않습니다. 지역 경도 보정 없이 UTC+9를 사용하는 현재 계산 정책에 맞춘 23시 기본값입니다.
- 사주 결과는 여덟 글자, 일간·일주, 오행·음양, 십성, 구조·균형, 대운·세운, 합·충·형·파·해, 신살의 8장입니다. 짧은 요약을 보고 궁금한 장을 펼칩니다.
- 생년월일시와 결과는 전송하거나 영구 저장하지 않습니다. 페이지 안에서 백과를 다녀오면 메모리에 유지되지만 새로고침하면 지워집니다. 입력과 결과 지우기도 가능합니다.
- 용어 상세의 주소는 공유할 수 있습니다. 사주 개인 입력은 URL에 넣지 않습니다.

## 데이터와 검증 상태

정본은 `source/saju_terms.json`입니다. 기존 245개 용어 ID·내용, 150개 관계, 8개 규칙, 4개 출처를 수정하지 않았습니다. SQLite와 CSV, 원래 HTML도 `source/`에 그대로 보존합니다. 추가 설명은 없는 내용을 생성하지 않고 검토 중으로 표시합니다. 출처 목록은 개별 고전 원문 검증 완료를 뜻하지 않습니다.

`scripts/validate.cjs`는 빌드 전에 JSON 파싱, ID 중복, 관계의 양 끝 ID, 최소 수량, 정본과 배포 데이터의 항목별 동등성을 검사합니다. `source-baseline.json`의 원본 해시와도 비교합니다.

데이터 수정은 운영자가 백업 후 JSON의 기존 ID와 필드를 유지하며 수행합니다. 사용자는 코드나 JSON을 직접 수정할 필요 없이 변경 요청을 전달하면 됩니다. SQLite·CSV 동기화가 필요하면 별도 명시적 변환 작업이 필요하며 자동으로 동기화된다고 간주하지 않습니다.

## 기술 선택

명세 3절의 대안인 순수 HTML/CSS/JavaScript를 선택했습니다. 고정된 소규모 데이터와 단순한 화면에 React/Vite 런타임이 필요하지 않아 의존성과 배포 복잡도를 줄였습니다. `npm run build`는 검사 후 `dist/`를 생성합니다. 백엔드·외부 폰트·CDN·분석 도구가 없고 핵심 기능은 같은 사이트의 파일만 사용합니다. 표준 DOM·details·URL 해시 라우팅·localStorage API를 사용합니다. 루트 사용자 페이지와 프로젝트 하위 경로 모두 상대 자산 경로로 동작합니다.

사주 계산은 MIT 라이선스 `lunar-javascript@1.7.7`, 한국 음력 변환은 MIT `korean-lunar-calendar@0.4.0`를 고정 버전으로 사용합니다. 배포 파일 안에 라이브러리와 라이선스를 포함합니다. 런타임 외부 API를 호출하지 않습니다. 빌드는 CSS/JS의 내용 해시를 자산 URL에 넣어 모바일 브라우저의 이전 버전 캐시를 구분합니다.

## 계산 범위

- 1900~2050년, 고정 UTC+9의 한국 표준시 입력. 양력과 한국 음력/윤달 변환.
- 연주·월주는 절입 기준이며 라이브러리의 중국 UTC+8 절기 시각과 1시간 차이를 보정합니다. 일주·시주는 한국 날짜와 입력 시각으로 계산합니다.
- 일주 변경은 23시 또는 0시를 선택합니다. 시주는 선택한 일간 기준 오서둔으로 산출하여 자정 기준과 자시 기준이 일치하도록 합니다.
- 오행은 표면 8글자의 동일 가중 개수이며, 계절·지장간 가중 강약 점수가 아닙니다. 음양은 천간·지지의 고정 분류입니다.
- 십성은 일간과 천간/지장간의 관계입니다. 일간·일주의 해설은 기존 용어 정의를 사용합니다.
- 대운은 라이브러리 방식 2(절입 거리의 분 단위 환산), 남녀·연간 음양 순역 기준입니다. 시작일과 9개 대운·각 10년 세운을 표시합니다. 연도 목록의 경계는 라이브러리의 연 단위 표시이고 정밀 교운 시각은 별도 검토 대상입니다.
- 세운의 연간지는 해당 연도 입춘부터 다음 입춘까지입니다. 현재 연도 기준 앞 2년·뒤 8년을 표시합니다.
- 시간 미상은 정오 기준 임시 3주, 6글자 오행입니다. 시주·대운은 산출하지 않습니다. 절기 경계일은 연·월주 불확실성을 표시합니다.
- 관계는 천간합·육합·지지충·삼합·방합과 형(쌍 기준 후보·자형)·파·해를 탐지합니다. 형의 방향·삼형 완성·거리·합화·반합·암합·천간충 작용 판정은 제공하지 않습니다.
- 신살은 일간 기준 천을귀인, 일지 기준 도화·역마·화개의 네 종류를 확인합니다. 기준 글자·대상 글자·해당 기둥을 표시합니다. 전체 29개 백과 항목을 모두 계산하는 기능은 아닙니다.
- 신강·신약·격국·용신 자동 판정은 제공하지 않습니다. 월지와 동일 일간 지장간의 위치를 관찰하고 각 개념으로 연결하는 학습 카드입니다.
- 진태양시·지역 경도·과거 한국 표준시 변경·서머타임을 반영하지 않습니다. 경계 출생, 과거 시각, 학파별 해석은 전문 만세력 대조가 필요합니다.

계산 라이브러리 문서: [lunar-javascript](https://github.com/6tail/lunar-javascript), [한국 음력 변환](https://github.com/usingsky/korean_lunar_calendar_js). 관계 및 보조 신살의 전통 표 대조: [ssaju analyze](https://github.com/golbin/ssaju/blob/main/src/analyze.ts), [ssaju constants](https://github.com/golbin/ssaju/blob/main/src/constants.ts). 이 대조는 고전 원전 검증이 아닙니다.

## 로컬 실행과 검사

Node.js 22 이상에서:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm run dev
```

기본 미리보기는 `http://127.0.0.1:4173/saju-encyclopedia/`입니다. 포트 충돌 시 `node scripts/serve.cjs 4183`로 실행할 수 있습니다.

```sh
npm run validate
npm test
```

자세한 실제 검증 결과와 미검증 환경은 `TEST_REPORT.md`에 기록합니다.

## 배포

공개 저장소 기본 브랜치는 `main`, GitHub Settings → Pages → Source는 **GitHub Actions**입니다. `.github/workflows/deploy.yml`이 설치·검증·테스트·빌드 후 공식 Pages 업로드/배포 Actions를 실행합니다. `dist/`는 커밋하지 않고 배포 산출물로만 업로드합니다. 워크플로는 build의 `contents: read`, deploy의 `pages: write`/`id-token: write`만 사용합니다.

프로젝트 페이지의 새로고침과 직접 진입은 `#/term/T0001`처럼 해시 경로를 사용하므로 별도 404 우회가 필요 없습니다. 실제 배포 확인 전에는 예정 주소를 성공 주소로 보고하지 않습니다.
